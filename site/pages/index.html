A rack-mount control surface for show infrastructure

A touchscreen and a row of keys in the rack, running the apps your show needs side by side: route a video router, watch LED processors and media servers, check the network, take presets on a switcher, drive PTZ cameras or Companion. Use it at the rack or from any browser on the network.

Several modules at once

Each app is a module. Run as many as the unit has memory for: one is in front with the screen and every key, the others keep watching their equipment in the background. After a power cut the unit picks up where it left off.

The device is in charge

Modules read live state from the equipment they control and never replay it. Starting, restoring or reconnecting only reads; only an operator's tap sends a command.

Signed, and checked on the unit

The controller and every module ship as signed releases. A unit installs only what checks out against the publisher's key, and only when someone taps Install or Update.
