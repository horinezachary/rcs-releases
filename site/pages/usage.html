Using it

Everything is reachable from the icon strip on the left of the screen, or from the menu bar in the web view.

Home and modules

  • Home sits at the top of the strip and lists the installed modules, with the running ones marked. Tap one to start it or bring it to the front.
  • Starting a module while others run asks whether to run it alongside them or replace one, and you pick which. If memory is low, the question says so and suggests replacing one; Start anyway is still there.
  • The module in front has the screen and the keys, and its own icons sit below Home. Modules in the background keep working. Going Home leaves everything running, so you can reach Settings without closing anything. Stop a module from Home when you no longer need it.
  • After a power cut, the unit starts every module that was running again, with its settings.

Saves

A save holds a module's own settings and presets, never the live state of the equipment, so restoring one reads the equipment again and changes nothing on it. Save under a name, restore later (you're warned about unsaved changes), or delete saves you no longer need. Stopping a module keeps its saves; Reset in Settings clears its working data but keeps named saves.

Saves include the module's logins and API keys. Downloading a save from the web view asks for a passphrase to lock them in the file (leave it blank to leave them out), and uploading it asks for the passphrase again.

Settings

  • Network: DHCP or a static address, typed on the keys.
  • Web access: turns the web view on or off, with an optional PIN. The same PIN can lock the panel; while it's locked, the keys become a PIN pad.
  • Modules: install from the index, update, upload a zip, reset or remove. Removing a module keeps its data and saves.
  • Updates: checks for module and controller updates. Nothing installs until you tap Update.
  • System: Dark or Light and your own themes (colours, logo and title), Developer mode (turned on at the panel only) and factory reset, which wipes module data, saves and saved themes and returns networking to DHCP, but keeps installed modules.

The web view

Open http://rack-surface.local/ (or the unit's address). The header has the logo, the installation name, the address, Lock, Hide mirror and Settings. Under the mirror of the panel (which you can tap, keys included) a bar holds Home and each running module, then the pages and Saves of the one you're looking at. Modules other than the panel's and the one you're viewing show as an icon with a status dot. Modules show more detail here than fits on the panel, and every page scrolls as one page, phone included.

Setting up a unit

  1. Download the SD card image from the download section.
  2. Write it with Raspberry Pi Imager (Choose OS › Use custom). Its settings can add Wi-Fi.
  3. Boot the unit; the panel comes up on its own. Install modules from Settings › Modules.
