Using it

Everything is reachable from the icon strip on the left of the screen, or from the menu bar in the web view.

Home and modules

  • Home sits at the top of the strip and lists the installed modules. Tap one to start it. Starting a different module asks before it replaces the one running.
  • While a module runs, its own icons sit below Home. Going Home leaves it running, so you can reach Settings without closing it.
  • After a power cut, the unit starts the last module again with its settings.

Saves

A save holds a module's own settings and presets, never the live state of the equipment. Save under a name, restore later (you're warned about unsaved changes), or delete saves you no longer need. Stopping a module keeps its saves; Reset in Settings clears its working data but keeps named saves.

Settings

  • Network: DHCP or a static address, typed on the keys.
  • Web access: turns the web view on or off, with an optional PIN. The same PIN can lock the panel; while it's locked, the keys become a PIN pad.
  • Modules: install from the index, update, upload a zip, reset or remove. Removing a module keeps its data and saves.
  • Updates: checks for module and controller updates. Nothing installs until you tap Update.
  • System: Dark or Light and your own themes (colours, logo and title), Developer mode (turned on at the panel only) and factory reset, which wipes module data, saves and saved themes and returns networking to DHCP, but keeps installed modules.

The web view

Open http://rack-surface.local/ (or the unit's address). The menu bar has Home first, the running module's pages, Saves, a mirror of the panel you can tap, and Settings last. Modules can show more detail here than fits on the panel.

Setting up a unit

  1. Download the SD card image from the download section.
  2. Write it with Raspberry Pi Imager (Choose OS › Use custom). Its settings can add Wi-Fi.
  3. Boot the unit; the panel comes up on its own. Install modules from Settings › Modules.
